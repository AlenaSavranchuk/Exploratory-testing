# #1_ИТ: Неактивны элементы выпадающего меню пользователя

### Полное описание
При клике на кнопку **«User»** или иконку аккаунта в шапке сайта на главной странице выпадающее меню отображается визуально, однако взаимодействие с его пунктами (Профиль, Выход и др.) невозможно — клики игнорируются системой.

### Приоритет
`Critical` 

### Предусловия
1. Пользователь успешно авторизован в системе.
2. Пользователь находится на главной странице.

### Шаги по воспроизведению
1. Нажать на кнопку **«User»** или на круглую иконку профиля в правом верхнем углу.
2. В открывшемся выпадающем списке кликнуть на любой пункт (например, "Профиль").

### Ожидаемый результат
При клике на пункт меню происходит переход в соответствующий раздел или выполняется действие (выход из системы).

### Фактический результат
Элементы меню неактивны. Визуальный отклик на клик отсутствует, переход не происходит.

# #2_ИТ: Добавление самолета с вместимостью 1000 мест

### Полное описание
При добавлении самолета на роли администратора:
1. Не указаны ограничения по количеству мест (макс,мин).
2. Можно добавить самолет с вместимость 1000 пассажиров.

### Приоритет
`Critical` 

### Предусловия
1. Пользователь успешно авторизован в системе.
2. Пользователь в роли Администратора. 
3. Пользователь находится на странице добавления нового самолета URL: https://ftb.mentorpiece.org/aircraft/new

### Шаги по воспроизведению
1. Успешно авторизироваться в системе
2. Перейти на любую вкладку "Рейсы" или "Поиск" через верхнее меню на главной странице сайта
3. Сменить роль через кнопку в верхнем правом углу, кликнув по User или оранжевый кружочек на роль администратора
4. На главной странице сайта перейти в раздел "Самолеты" через кнопку в верхнем меню
5. На странице "Самолеты" кликнуть по кнопке "Добавить самолет" 

### Ожидаемый результат
1.При заполнении всех строк добавления самолета: производитель (рандомное значение), модель (рандомное значение).
2.При заполнении поля "Количество мест" ввести значение 1000 - выдаст ошибку, например: не верное значение.

### Фактический результат
Никакого сообщения об ошибке нет. Самолет с количеством мест 1000 успешно добавлен и отображается на странице "Самолеты"

# #23_ИТ: Вся область формы загрузки CSV файла с данными самолетов работает как кнопка выбора файла при нажатии на нее

### Полное описание
При наведении курсора и нажатии на область формы загрузки CSV файла с данными самолетов, она срабатывает как кнопка загрузки файла

### Приоритет
`Low`

### Предусловия
1. Успешно пройти авторизацию в системе
2. Находится на странице "Самолеты" URL: [https://ftb.mentorpiece.org/aircrafts](https://ftb.mentorpiece.org/aircrafts)

### Шаги по воспроизведению
1. Успешно авторизоваться на сайте
2. Убедиться, что в системе роль админа
3. Перейти на страницу "Самолеты" в верхнем меню главной страницы сайта
4. Прокрутить до самого низа, навести курсор на любую область формы загрузки файла CSV

### Ожидаемый результат
При наведении на область формы ничего не происходит

### Фактический результат
При наведении курсора разную область формы она везде срабатывает как кнопка выбора файла
