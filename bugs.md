**URL сайта:** [https://ftb.mentorpiece.org/?lang=ru](https://ftb.mentorpiece.org/?lang=ru)

| ID | 4_ИТ |
| :--- | :--- |

## 2. Краткое описание
При попытке применить случайный промокод под полем ввода отображается нелогичное сообщение об ошибке, не соответствующее контексту валидации.

## 3. Подробное описание
На странице активации промокода при вводе произвольных данных и нажатии кнопки «Применить» система выдает ошибку, которая не объясняет причину отказа (неверный формат, несуществующий код или ошибка сервера). 

*   **Фактический результат:** Под полем «Промокод» появляется нелогичный текст ошибки.
*   **Ожидаемый результат:** Система должна выдавать понятное пользователю сообщение (например, «Промокод не найден» или «Неверный формат e-mail»), а также подсвечивать поля, не прошедшие валидацию.

## 4. Шаги по воспроизведению
1. Перейти на главную страницу [Mentorpiece](https://ftb.mentorpiece.org/?lang=ru).
2. Нажать кнопку **«Промокод»** (расположена рядом с кнопкой «Войти»).
3. В форме ввода заполнить поля (включая текстовое поле «Промокод») рандомными значениями.
4. Нажать кнопку **«Применить»**.
5. Обратить внимание на текст ошибки под полем ввода промокода.

## 5. Окружение
*   **ОС:** Windows 11 Home Single Language
*   **Браузер:** Chrome 144.0.7559.133 (Official Build, 64-bit)

## 6. Приоритет и важность
*   **Важность:** `Средняя` (UI/UX дефект, мешающий пользователю понять причину ошибки).
*   **Срочность:** `Средняя` (желательно исправить до релиза).

# Баг-репорт: Несоответствие стилей элементов в форме «Применить промокод»

**URL сайта:** [https://ftb.mentorpiece.org/?lang=ru](https://ftb.mentorpiece.org/?lang=ru)

| ID | 5_ИТ |
| :--- | :--- |

## 2. Краткое описание
Визуальное неединообразие элементов в форме активации промокода: кнопка **«Отмена»** меняет цвет и курсор некорректно, а лейбл **«Адрес электронной почты»** имеет отличную от других полей прозрачность.

## 3. Подробное описание
В форме «Применить промокод» выявлено несколько дефектов верстки и поведения:
1.  **Кнопка «Отмена»**: Изначально серая (отличается от «Применить»). При наведении курсор меняет вид на `wait` (крутящийся индикатор загрузки), а кнопка меняет цвет на оранжевый.
2.  **Текстовые метки (Labels)**: Надпись «Адрес электронной почты» заметно бледнее (выше прозрачность), чем надпись «Промокод».

*   **Фактический результат:** Кнопки и надписи имеют разные стили; некорректный тип курсора (`wait`) при наведении на «Отмена».
*   **Ожидаемый результат:** Кнопки «Отмена» и «Применить» выдержаны в едином стиле. Курсор при наведении — `pointer`. Все надписи над полями имеют одинаковую яркость и прозрачность.

## 4. Шаги по воспроизведению
### Кейс №1 (Кнопка):
1. Открыть главную страницу [Mentorpiece](https://ftb.mentorpiece.org/?lang=ru).
2. Нажать кнопку **«Промокод»**.
3. Обратить внимание на цвет кнопки **«Отмена»**.
4. Навести курсор на кнопку **«Отмена»** и проверить вид курсора.

### Кейс №2 (Надписи):
1. Находясь в той же форме, сравнить визуальную яркость текста **«Адрес электронной почты»** и **«Промокод»**.

## 5. Окружение
*   **ОС:** Windows 11 Home Single Language
*   **Браузер:** Chrome 144.0.7559.133 (Official Build, 64-bit)

## 6. Приоритет и важность
*   **Важность:** `Средняя` (UI-баг, нарушение гайдлайнов).
*   **Срочность:** `Низкая/Средняя` (перед релизом для обеспечения визуальной целостности).

## 7. Комментарии
Курсор в виде круга загрузки при наведении на «Отмена» вводит пользователя в заблуждение, создавая впечатление, что процесс уже запущен. Рекомендуется заменить на стандартный `cursor: pointer`.

# Баг-репорт: Некорректный тип данных для полей времени в таблице `flight` (MySQL schema)

**URL сайта:** [https://ftb.mentorpiece.org/?lang=ru](https://ftb.mentorpiece.org/?lang=ru)

| ID | 7_ИТ |
| :--- | :--- |

## 2. Краткое описание
В файле **MySQL schema** (блок «Все уровни приложения») для хранения временных значений в таблице `flight` используется тип данных `VARCHAR` вместо специализированного типа `TIME`.

## 3. Подробное описание
При анализе схемы базы данных, доступной по ссылке в блоке «Все уровни приложения», обнаружено несоответствие типов данных их смысловому значению. Поля, предназначенные для хранения времени в таблице `flight`, определены как строки.

*   **Фактический результат:** В определении таблицы `flight` для временных полей указан тип `VARCHAR`.
*   **Ожидаемый результат:** Для обеспечения целостности данных и возможности выполнения арифметических операций со временем должен использоваться тип `TIME`.

## 4. Шаги по воспроизведению
1. Открыть главную страницу [Mentorpiece](https://ftb.mentorpiece.org/?lang=ru).
2. Прокрутить страницу вниз до блока **«Все уровни приложения»**.
3. Кликнуть по гиперссылке **«MySQL schema»**.
4. В открывшейся вкладке с текстовым дампом БД найти определение таблицы `CREATE TABLE flight (...)`.
5. Проверить типы данных для полей, содержащих время.

## 5. Окружение
*   **ОС:** Windows 11 Домашняя для одного языка
*   **Браузер:** Chrome 144.0.7559.133 (Official Build, 64-bit)

## 6. Приоритет и важность
*   **Важность:** `Высокая` (ошибка проектирования БД может привести к проблемам при фильтрации и расчетах на бэкенде).
*   **Срочность:** `Высокая` (рекомендуется исправить до финализации архитектуры релиза).

## 7. Комментарии
Сделала эту ошибку через ИИ, считаю,что просмотр всех строк непродуктивно для времени тестировщика. Потом проверила указанную ошибку в коде,действительно, тип был не верный для БД. Так что, баг найден через ИИ и проверен вручную.
