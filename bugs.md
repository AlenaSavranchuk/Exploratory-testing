# #1_ИТ: Некорректная локализация кнопки личного кабинета

**Заголовок:** Кнопка "User" в правом верхнем углу отображается на английском языке при выбранном русском интерфейсе

### Полное описание
После выбора русского языка и успешной авторизации пользователь перенаправляется на главную страницу, где кнопка перехода в личный кабинет сохраняет англоязычное название **"User"** вместо локализованного варианта.

### Приоритет
`Medium`

### Окружение
*   **ОС:** Windows 11 Home
*   **Браузер:** Chrome 144.0.7559.133 (64-bit)
*   **URL:** [ftb.mentorpiece.org](https://ftb.mentorpiece.org)

### Предусловия
1. Пользователь не авторизован.
2. Выбран любой язык интерфейса, кроме английского. 

### Шаги по воспроизведению
1. Открыть форму входа на сайте.
2. Ввести валидные логин и пароль.
3. Нажать кнопку **"Войти"**.
4. Обратить внимание на текстовую надпись кнопки в правом верхнем углу.

### Ожидаемый результат
Надпись на кнопке отображается на выбранном языке: **"Пользователь"**.

### Фактический результат
Надпись на кнопке отображается на английском языке: **"User"**.

# #2_ИТ: Неактивны элементы выпадающего меню пользователя

**Заголовок:** Пункты выпадающего меню пользователя не реагируют на нажатие после авторизации

### Полное описание
При клике на кнопку **«User»** или иконку аккаунта в шапке сайта выпадающее меню отображается визуально, однако взаимодействие с его пунктами (Профиль, Выход и др.) невозможно — клики игнорируются системой.

### Приоритет
`Critical` (Высокая срочность)

### Окружение
*   **ОС:** Windows 11 Домашняя
*   **Браузер:** Chrome 144.0.7559.133 (Official Build, 64-bit)
*   **URL:** [ftb.mentorpiece.org](https://ftb.mentorpiece.org)

### Предусловия
1. Пользователь успешно авторизован в системе.
2. Пользователь находится на главной странице.

### Шаги по воспроизведению
1. Нажать на кнопку **«User»** или на круглую иконку профиля в правом верхнем углу.
2. В открывшемся выпадающем списке кликнуть на любой пункт (например, "Профиль").

### Ожидаемый результат
При клике на пункт меню происходит переход в соответствующий раздел или выполняется действие (выход из системы).

### Фактический результат
Элементы меню неактивны. Визуальный отклик на клик отсутствует, переход не происходит.

# #4_ИТ: Некорректное сообщение об ошибке в форме «Применить промокод»

### Полное описание

# #5_ИТ: Несоответствие стилей элементов в форме «Применить промокод»

### Полное описание
В форме активации промокода выявлены визуальные дефекты верстки и некорректное поведение элементов:
1. Кнопка **«Отмена»** при наведении меняет курсор на индикатор загрузки и окрашивается в оранжевый цвет, что не соответствует изначальному (как я поняла, цвету). 
2. Текстовая метка **«Адрес электронной почты»** имеет иную прозрачность (бледнее), чем метка поля «Промокод», что нарушает единообразие интерфейса.

### Приоритет
`Medium` / `Low` (UI/UX дефект)

### Окружение
*   **URL:** [https://ftb.mentorpiece.org/?lang=ru](https://ftb.mentorpiece.org/?lang=ru)
*   **ОС:** Windows 11 Home Single Language
*   **Браузер:** Chrome 144.0.7559.133 (Official Build, 64-bit)

### Предусловия
1. Открыта главная страница сайта.
2. Вызвано модальное окно/форма «Промокод».

### Шаги по воспроизведению
1. Нажать на кнопку **«Промокод»** в шапке сайта.
2. Навести курсор мыши на кнопку **«Отмена»** и проверить тип курсора и смену цвета.
3. Сравнить визуальную яркость (прозрачность) надписей **«Адрес электронной почты»** и **«Промокод»** над соответствующими полями ввода.

### Ожидаемый результат
*   Кнопка «Отмена» имеет стандартный курсор "стрелочки" при наведении.
*   Стили кнопок «Отмена» и «Применить» согласованы между собой стилем/цветом и тд.
*   Все текстовые метки над полями имеют одинаковый цвет и уровень прозрачности.

### Фактический результат
*   При наведении на «Отмена» отображается курсор загрузки.
*   Надпись «Адрес электронной почты» заметно бледнее остальных элементов формы.

# #7_ИТ: Некорректный тип данных для полей времени в таблице flight (MySQL schema)

### Полное описание
В схеме базы данных MySQL (блок **«Все уровни приложения»**) для полей, предназначенных для хранения временных значений в таблице `flight`, используется строковый тип данных `VARCHAR` вместо специализированного типа `TIME`. Это нарушает принципы проектирования БД и затрудняет дальнейшую работу с данными (фильтрацию, расчеты, сортировку).

### Приоритет
`High` (Высокая важность/срочность)

### Окружение
*   **URL:** [https://ftb.mentorpiece.org/?lang=ru](https://ftb.mentorpiece.org/?lang=ru)
*   **ОС:** Windows 11 Домашняя для одного языка
*   **Браузер:** Chrome 144.0.7559.133 (Official Build, 64-bit)

### Предусловия
1. Доступ к главной странице сайта.
2. Возможность просмотра текстовых файлов/дампов БД по внешним ссылкам.

### Шаги по воспроизведению
1. Открыть главную страницу **Mentorpiece**.
2. Прокрутить страницу вниз до блока **«Все уровни приложения»**.
3. Кликнуть по гиперссылке **«MySQL schema»**.
4. В открывшемся дампе БД найти SQL-запрос `CREATE TABLE flight` с помощью поиска.
5. Проверить определения типов данных для полей, содержащих информацию о времени.

### Ожидаемый результат
Для хранения времени в таблице `flight` используется тип данных `TIME` (или аналогичный временной тип), обеспечивающий целостность данных и возможность выполнения арифметических операций на стороне СУБД.

### Фактический результат
В определении таблицы `flight` для временных полей указан тип `VARCHAR`.
